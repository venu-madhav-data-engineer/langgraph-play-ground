# Core Package (`packages/core`)

This package provides common state definitions, base classes, and helper utilities shared across all applications and examples in the monorepo.

## Modules

- `core.state`: Common TypedDict and Pydantic models for graph states.
- `core.utils`: Graph visualization, logging, and workflow helper functions.

## Usage

```python
from core.state import BaseAgentState
from core.utils import print_graph_ascii
```
