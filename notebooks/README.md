# Notebooks (`notebooks/`)

This directory is reserved for Jupyter Notebooks used for interactive experimentation, prototyping agent behaviors, and testing LangSmith traces.

## Getting Started

1. Install Jupyter:
   ```bash
   pip install jupyterlab
   ```
2. Start Jupyter:
   ```bash
   jupyter lab notebooks/
   ```
3. Import core modules:
   ```python
   from core.state import BaseAgentState
   from tools import calculator
   ```
